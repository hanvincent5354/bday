# Birthday Celebration PWA 🎂

An interactive, customizable Progressive Web App (PWA) to celebrate birthdays with real-time candle blowing, celebratory animations, and a 3D greeting card.

## ✨ Features
- 🎙️ **Web Audio Blow Detection**: Blow into the microphone (<250Hz breath frequency) to blow out the candles.
- 🐧 **Chibi Character Micro-Animations**: Penguin, Cat, and Dog spring in and cheer.
- 🎨 **Dynamic Customizer & Theming**: Live-customize the recipient's name, age, message, photo, and 6 curated color themes.
- 🔗 **One-Click Shareable Link**: Send personalized celebration links using query parameters (e.g. `?name=Sarah&age=30&theme=emerald`).
- 📱 **PWA Ready**: Works offline and can be installed as an app on iOS and Android.

## 🚀 Deployment (GitHub Pages)

1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/(root)`.
4. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`.
